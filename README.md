# pair-wise-yf-45 影视剧组拍摄通告与资源冲突编排

源提示词摘要：为剧组制片、导演、演员统筹和场记提供通告编排工作台，维护场次、演员档期、场地与器材占用，自动发现资源冲突，支持拖拽排序、状态流转、版本快照、撤销恢复和离线草稿。

## 档期回执对账

通告排好后，场地与器材供应商各回一份「档期回执」（编号 + 有效期）：

- 每场在通告单上逐条挂接：场地 1 条、每件器材各 1 条，系统核对回执是否有效、有效期是否覆盖拍摄日。
- 供应商**临时撤档**或**改期到达**后，引用该回执且未开拍的场次自动退回「待核对」并汇集进冲突中心（撤档提示演员/车辆勿照旧前往）；`拍摄中 / 已完成` 的场次保住现场，改动只影响后续场次。
- 改期生成**新回执编号**，旧回执标记「已改期」，需场次手动改挂，旧编号不得顶替。
- 场次的时间、场地或器材一旦变更，对应旧回执立即作废留痕（时间变动作废全部、场地变动作废场地、器材增减作废对应器材），场次退回「待核对」重新对账。
